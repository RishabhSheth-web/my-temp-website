ESP32 firmware (paste into Wokwi sketch.ino)

Add ESP32Servo in Wokwi’s libraries.txt. The original suggestion was missing the servo objects, the library and the pin setup, and it read each LDR once without averaging. This version fixes those.

#include <ESP32Servo.h>

const int PIN_TL = 32, PIN_TR = 33, PIN_BL = 34, PIN_BR = 35; // ADC1 only (safe with WiFi)
const int PIN_YAW = 18, PIN_PITCH = 19;
const int TOLERANCE = 50;       // ADC deadband, about 1.5 degrees
const int STEP_MS = 20;         // one 1-degree step per loop
const bool INVERT_LDR = false;  // set true if your LDR module reads LOWER in light

Servo servoYaw, servoPitch;
int posYaw = 90, posPitch = 90;

int readLdr(int pin) {
  long sum = 0;
  for (int i = 0; i < 8; i++) sum += analogRead(pin);
  int v = sum / 8;
  return INVERT_LDR ? 4095 - v : v;
}

void updateSolarTracker() {
  int tl = readLdr(PIN_TL), tr = readLdr(PIN_TR);
  int bl = readLdr(PIN_BL), br = readLdr(PIN_BR);

  int avgTop = (tl + tr) / 2,  avgBottom = (bl + br) / 2;
  int avgLeft = (tl + bl) / 2, avgRight = (tr + br) / 2;

  if (abs(avgTop - avgBottom) > TOLERANCE) {
    posPitch += (avgTop > avgBottom) ? 1 : -1;
    posPitch = constrain(posPitch, 0, 180);
    servoPitch.write(posPitch);
  }
  if (abs(avgLeft - avgRight) > TOLERANCE) {
    posYaw += (avgRight > avgLeft) ? 1 : -1;
    posYaw = constrain(posYaw, 0, 180);
    servoYaw.write(posYaw);
  }
  Serial.printf("TL %d TR %d BL %d BR %d | yaw %d pitch %d\n",
                tl, tr, bl, br, posYaw, posPitch);
}

void setup() {
  Serial.begin(115200);
  servoYaw.setPeriodHertz(50);
  servoPitch.setPeriodHertz(50);
  servoYaw.attach(PIN_YAW, 500, 2400);
  servoPitch.attach(PIN_PITCH, 500, 2400);
  servoYaw.write(posYaw);
  servoPitch.write(posPitch);
}

void loop() {
  updateSolarTracker();
  delay(STEP_MS);
}

If the panel turns away from the light in Wokwi, set INVERT_LDR to true. For the integrated project, call updateSolarTracker() from the central ESP32 loop (Suryajith’s code) without any blocking delay(): use a millis() timer instead.

Panel and battery setup

  • 6 V, 1 to 2 W mini solar panel → TP4056 charger module with protection → 1× 18650 cell.
  • Battery → MT3608 boost set to 5 V → both servos and the ESP32 VIN. Add a 470 µF capacitor across the servo rail to absorb start-up spikes.
  • For the monitoring subsystem (Samrudh), the INA219 sits in series on the panel-to-charger line.
  • Use MG90S or SG90 servos; both are fine for a panel under 100 g.

In Wokwi, use the ESP32 DevKit, 4 photoresistor modules (or LDR plus 10 kΩ), 2 servos and a 5 V source, with all grounds shared.

CAD modelling steps (Fusion 360 or SolidWorks)

  1. Base: 100 × 100 × 15 mm plate with a pocket for the yaw servo (SG90 body 23 × 12.5 mm) and four mounting holes.
  2. Turntable: circular disc, 60 mm diameter, fixed to the yaw servo horn.
  3. Pitch bracket: U-bracket on the disc with a pocket for the pitch servo on one arm and a bearing hole on the other, so the panel axle is supported at both ends.
  4. Panel bed: 120 × 70 mm frame, 3 mm thick, with a cut-out matching the panel and the axle attached to the pitch servo horn.
  5. LDR shroud: a cross of 3 mm walls, 15 mm tall, splitting a 40 × 40 mm square into four quadrants, each with a 5 mm LDR hole. Mount it flat on the panel face.
  6. Motion study: add revolute joints, yaw 0 to 180° and pitch 0 to 180°. Check that the panel clears the bracket at 0° and 180°, and leave 40 mm of slack in the cable loop through the turntable.
  7. Export: render an exploded view and an assembly animation for the report.
